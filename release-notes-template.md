# Dockpulse v{VERSION}

### What's New
- Professional visual style without emoji in the CLI, TUI, or documentation
- Standalone TUI built with Bubble Tea and Lip Gloss
- Interactive Docker container management: logs, inspection, start, stop, and restart
- Host, Docker, Docker Compose, and Docker Swarm monitoring
- Linux builds for amd64 and arm64

### Installation
```bash
# Debian / Ubuntu / Linux Mint (amd64)
wget https://github.com/{REPO_OWNER}/{REPO_NAME}/releases/download/v{VERSION}/dockpulse_{VERSION}_amd64.deb
sudo dpkg -i dockpulse_{VERSION}_amd64.deb

# Standalone binary
tar -xzf dockpulse_v{VERSION}_{OS}_{ARCH}.tar.gz
./dockpulse
```
